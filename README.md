## 🎯 Security Focus

### Offensive Security / Bug Bounty
Hunting on public programs with an emphasis on logic flaws and authentication issues rather than low-hanging automated findings.

- Broken access control, IDOR, and privilege escalation
- Authentication and session management flaws
- SSRF, injection, and insecure deserialization
- API security testing (REST and GraphQL)
- Recon automation and custom tooling to cut down manual work

### Defensive Security
Applying the same knowledge in the other direction.

- Secure code review and threat modeling
- Hardening application and infrastructure configs
- Detection engineering and log analysis
- Building secure-by-default services rather than patching after the fact
